"Piranha Chasing Sloth" is an interactive project that explores real-time communication between physical sensing and digital representation through Arduino–p5 integration. The system features a small climbing robot, the “Sloth,” whose two front limbs are actuated by a servo motor through a four-bar linkage mechanism. An ultrasonic sensor mounted on the Arduino continuously measures the distance to an approaching object, metaphorically framed as a “piranha.” This distance data is transmitted to p5, where it is visualized as a responsive on-screen piranha image and corresponding textual warnings. When the object is far away, the system remains calm: the Arduino LED turns green, p5 displays a “No worries” message, and the Sloth stays still. As the object approaches, the LED shifts to blue, a piranha image appears and enlarges with proximity, and users can manually control the Sloth’s movement speed via mouse input—walking or running. When the object reaches a critical distance, the interface turns red with a “DANGER!” warning, the Arduino LED switches to red, and the Sloth automatically accelerates. Once the threat retreats to a safe range, the system resets, returning the Sloth to rest and restoring a calm visual and physical state.
